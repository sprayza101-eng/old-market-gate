# ด่านตลาดเก่า — ออนไลน์

เกมบลัฟค้าของเถื่อน 2–20 คน เล่นผ่านเบราว์เซอร์คนละเครื่อง สร้างห้อง ส่งลิงก์หรือรหัสห้องให้เพื่อนเข้ามาเล่น

## ในโฟลเดอร์นี้
- `server.js` — เซิร์ฟเวอร์ (ใช้ Node.js ล้วน **ไม่ต้อง npm install**) ถือไพ่ทั้งหมดไว้ แล้วส่งให้แต่ละคนเห็นเฉพาะของตัวเอง
- `engine.js` — กติกาเกม ใช้ร่วมกันทั้งเซิร์ฟเวอร์และหน้าเว็บ
- `index.html` — หน้าเว็บของเกม
- `package.json` — ให้บริการโฮสต์รู้ว่าเริ่มเกมด้วยคำสั่งอะไร

## ลองเล่นในเครื่องตัวเองก่อน
1. ติดตั้ง Node.js เวอร์ชัน 18 ขึ้นไป (https://nodejs.org)
2. เปิดเทอร์มินัลในโฟลเดอร์นี้ แล้วรัน `node server.js`
3. เปิด http://localhost:3000 ในเบราว์เซอร์ สร้างห้อง แล้วเปิดอีกแท็บเพื่อทดลองเข้าเป็นผู้เล่นคนที่สอง
4. ถ้าเพื่อนอยู่ในวง Wi-Fi เดียวกัน ให้เพื่อนเปิด `http://<IP เครื่องคุณ>:3000`

## ให้เพื่อนทั่วโลกเข้ามาเล่น (โฮสต์ฟรี)

### ทางที่ 1: Render (แนะนำ)
1. สมัคร GitHub แล้วสร้าง repository ใหม่ อัปโหลดไฟล์ทั้ง 4 ไฟล์ขึ้นไป
2. สมัคร https://render.com แล้วกด New → **Web Service** → เลือก repository นั้น
3. ตั้งค่า: Runtime = **Node**, Build Command = เว้นว่าง (หรือ `npm install`), Start Command = `node server.js`, Instance Type = **Free**
4. กด Deploy รอสักครู่จะได้ลิงก์ เช่น `https://ชื่อ.onrender.com` ส่งลิงก์นี้ให้เพื่อนได้เลย
5. ข้อควรรู้: แพ็กเกจฟรีจะ "หลับ" เมื่อไม่มีคนใช้ประมาณ 15 นาที ครั้งแรกที่เปิดอาจรอ 30–60 วินาที

### ทางที่ 2: Replit
1. สร้าง Repl ใหม่แบบ Node.js แล้วอัปโหลดไฟล์ทั้ง 4 ไฟล์
2. กด Run แล้วเปิดลิงก์ที่ Replit แสดงในหน้าต่าง Webview ส่งลิงก์นั้นให้เพื่อน

(Railway, Fly.io หรือ VPS ทั่วไปก็ใช้ได้ ขอแค่รัน `node server.js` และรองรับ WebSocket)

## วิธีเล่น
1. คนหนึ่งกด "สร้างห้องใหม่" แล้วส่งลิงก์เชิญ (ปุ่ม "คัดลอกลิงก์เชิญ") หรือบอกรหัสห้อง
2. เพื่อนเปิดลิงก์ หรือกรอกรหัสห้องในหน้าแรก
3. โฮสต์ตั้งจำนวนรอบ แล้วกด "เริ่มเกม"
4. พ่อค้าทุกคนจัดไพ่และถุงพร้อมกัน นายด่านต่อรองผ่านแชตในห้อง พ่อค้าเสนอสินบนผ่านปุ่มในเกม

## ฟีเจอร์เพิ่มเติม
- **โฮสต์เตะผู้เล่น** ในหน้าห้องรอ กดปุ่ม "เตะ" ข้างชื่อ แล้วกดยืนยัน (คนที่ถูกเตะเข้าห้องใหม่ได้ถ้ายังมีรหัสห้อง)
- **โฮสต์ยุติเกม** ระหว่างเล่นกดปุ่ม "ยุติเกม" มุมบนเพื่อกลับห้องรอ (เช่น มีคนหลุดไม่กลับมา) แล้วเตะคนที่หลุดและเริ่มใหม่
- **เสนอเงินให้เปิดถุง** ผู้เล่นคนอื่น (ไม่ใช่นายด่านและไม่ใช่เจ้าของถุง) เสนอเงินให้นายด่านเปิดถุงที่กำลังตรวจอยู่ได้ จ่ายจริงเมื่อนายด่านเปิดถุงนั้นเท่านั้น ถ้านายด่านปล่อยผ่านหรือรับสินบนจากพ่อค้า จะไม่เสียเงิน

- **สินบนเป็นของ** พ่อค้าเสนอสินบนเป็นเหรียญ สินค้าจากแผงของตัวเอง และ/หรือไพ่จากมือ (รวมกันได้) นายด่านรับทั้งชุดหรือไม่รับเลย ของที่รับไปเข้าแผงของนายด่าน ไพ่ที่เสนอจากมือจะถูกเปิดให้ทุกคนเห็น

## ข้อควรรู้
- ห้องเก็บอยู่ในหน่วยความจำของเซิร์ฟเวอร์ ถ้าเซิร์ฟเวอร์รีสตาร์ท ห้องและเกมที่กำลังเล่นจะหายไป
- ถ้าเน็ตหลุดหรือปิดหน้าเว็บกลางเกม เปิดหน้าเดิมอีกครั้ง (หรือเข้าห้องด้วยรหัสเดิมและชื่อเดิม) จะกลับเข้าที่นั่งเดิมได้ เกมจะรอผู้เล่นที่หลุด
- ไม่มีระบบล็อกอิน ใครมีรหัสห้องก็เข้าได้ (ระหว่างที่ห้องยังอยู่ในหน้ารอเล่น) จึงควรส่งรหัสให้เฉพาะเพื่อน
- เซิร์ฟเวอร์ตรวจกติกาทุกการกระทำ และไม่ส่งไพ่ของคนอื่นไปยังเบราว์เซอร์ จึงแอบดูไพ่ไม่ได้
